SECTION 02 · BRAND ARCHITECTURE

Wordmark, monogram, lockups.

The Hexcoded wordmark is one locked unit — Outfit 900, plain UPPERCASE, never split or separated. The HEX monogram replaces it only where the wordmark won't fit (favicons, app icons, small social avatars). Phantom motion runs on both.

Wordmark do / don't

L06
✓ DO

Always UPPERCASE, never split. Plain HEXCODED, Outfit 900, letter-spacing -0.025em, ink colour on light surfaces / white on dark. Phantom shadow breathes behind it. That's the whole logo.

✗ DON'T

Never write the wordmark as HEX·CODED, HEX-CODED, HEX CODED, hex coded, or with any separator. Never recolour the letters. Never italicise. Never apply a gradient to the letterforms.

★Writing rule

Verb conjugations allowed: hexcode (present) · hexcoded (past) · hexcoding (gerund). Always lowercase when used as a verb — UPPERCASE HEXCODED is reserved for the brand mark. Don't force it — if a sentence reads better with "use Hexcoded," use that. Aim for ~50% verb use across marketing copy, falling to ~30% in product UI where functional language wins.

SECTION 09 · REFERENCE

System-wide don'ts.

Ten rules that govern every Hexcoded surface. Violations of any of these are bugs — push back when you see them.

✗ 01 · WORDMARK

Never split the wordmark. Always plain UPPERCASE HEXCODED. No HEX·CODED, HEX-CODED, HEX CODED, HEX_CODED, or any separator. (L06)

✗ 02 · COLOUR

Never use a non-green accent. The brand is Tech Green + neutrals. No purple, blue, or orange decoration — even in marketing. Semantic warning/danger are functional UI only. (L02)

✗ 03 · TYPE

Never substitute Outfit, Inter, or JetBrains Mono. No alternates, no system-font fallbacks at design time. (L05)

✗ 04 · MOTION

Never add ambient animation. Phantom breath on the brand mark is the only persistent loop. No parallax, no auto-play hero videos, no decorative loops. (L01)

✗ 05 · DARK MODE

Never ship a manual dark-mode toggle. Light is default; dark follows OS preference only. Revisit in v2. (L18)

✗ 06 · BUTTONS

Never put two primary buttons side by side. One primary per surface, always. Pair with a secondary or ghost for the next action.

✗ 07 · VOICE

Never use a banned word. The 12-word ban list (synergy · leverage · ecosystem · revolutionize · game-changing · disrupt · cutting-edge · solution · empower · seamless · world-class · next-generation) violates the brand voice on contact. (L12)

✗ 08 · ERROR COPY

Never apologise theatrically. No "Oops!". No "We're sorry — something went terribly wrong!". Voice A: what happened + what to do. (L24)

✗ 09 · LOGO DECORATION

Never decorate the wordmark. No gradients on the letters, no outlines, no italics, no stretched ratios. Phantom breath is the only allowed treatment. (L01)

✗ 10 · HARDCODING

Never hardcode values downstream. All colors, spacing, radii must come from @amplify-ai/tokens-hexcoded. Caught at CI via design-system lint.
