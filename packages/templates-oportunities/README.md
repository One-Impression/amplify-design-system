# @amplify-ai/templates-oportunities

Brand-applied templates for **Oportunities** — Amplify's intent-feed product for
Indian D2C brand teams.

All assets apply the locked brand:

- **Wordmark** `oportunities.` (single-P, lowercase, apricot period)
- **Palette** Apricot `#E89252`, cream `#FDF8F3`, ink `#0F0D0B`, ai-purple `#7B5BFF`
- **Type** Geist (display) + Inter (body) + JetBrains Mono (data)
- **Voice** Direct-confident in transactional surfaces, Tool-curious in marketing and
  empty states. The signature opener is `Heads up —`.

> Single-P spelling **"Oportunities"** is non-negotiable. Never autocorrect to
> "Opportunities." See `brand-oportunities/BRAND-DECISIONS.md`.

#### How to use with email providers

**Mailchimp / Sendgrid / Resend / SES** — paste the HTML body directly into the
template editor. All required attributes are already in place:

- Preheader text in a `display:none` div at the top
- `x-apple-disable-message-reformatting` meta tag
- Tables with `role="presentation"` (not data tables)
- Inline width on `<table>` (600 max)
- Hex colors inline everywhere (no `var()`)

**Variable substitution** — placeholders like `{{brandName}}`, `{{resetUrl}}` use
double-curly syntax. Replace with your provider's templating (Mailchimp uses
`*|MERGE|*`, Sendgrid uses `{{merge}}`, Resend uses React/JSX).

**Testing checklist before sending:**
1. Litmus / Email-on-Acid test (Outlook 2016+, Gmail web, iOS Mail, Apple Mail)
2. Plaintext fallback (auto-generated by most providers)
3. Unsubscribe footer is present on every marketing email
4. GST details on `payment-receipt.html` — never strip these from invoices to
   Indian customers (GSTIN compliance)
